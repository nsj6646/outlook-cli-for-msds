# 이슈 03: 엑셀 본문 플레이스홀더 치환, 표 자동 병합 및 HTML 개행 변환

Status: ready-for-agent

## Parent

- [PRD.md](../PRD.md)

## What to build

엑셀 파일의 `Body` 컬럼으로부터 가져온 수신인별 본문 텍스트에 대해 템플릿 처리 및 HTML 표 결합 기능을 완성합니다.
본문의 일반 텍스트 개행 문자(`\n`)를 HTML 단락 개행 태그(`<br>`)로 변환하고, 텍스트 내에 `{{table}}` 플레이스홀더가 존재할 경우 HTML 제품 표로 안전하게 대체합니다. 엑셀 본문에 `{{table}}` 플레이스홀더를 적지 않았더라도, 취급 제품 목록 표가 존재한다면 본문 텍스트 바로 아래에 적절한 간격을 두고 표가 자동 병합되어 삽입되도록 레이아웃 정합성을 강제합니다.

## Acceptance criteria

- [ ] 일반 텍스트 개행문자(`\n`)가 `<br>` 태그로 정상 변환되어 HTML 메일 본문 빌드 시 줄바꿈 구조가 보존됨.
- [ ] 엑셀 본문에 적힌 플레이스홀더(`{{table}}`, `{{고객명}}` 등)에 대해 딕셔너리 치환 처리가 정상적으로 완료됨.
- [ ] 본문에 `{{table}}`이 직접 적혀있지 않더라도, 취급 제품 데이터가 존재하면 본문 하단에 HTML 제품 표가 자동으로 덧붙여서 삽입됨.
- [ ] 템플릿과 본문 텍스트가 모두 누락된 극한 상황에서도 제품 표만을 활용한 기본 메일이 안전하게 작성됨.
