# PRD: 표 번호 자동 매김 및 메일 서명 자동 삽입

Status: ready-for-agent

## Problem Statement

실무자(배포 담당자)는 현재 엑셀 `TableData` 시트에 제품별 "번호"를 매번 수작업으로 기입해야 하며, 제품이 추가·삭제될 때마다 번호를 재정렬해야 하는 번거로움이 있습니다. 또한 발송되는 메일에 회사 서명이 빠져 있어 수신 고객사에게 비공식적인 인상을 줄 수 있습니다.

## Solution

1. 엑셀 `TableData` 시트에서 "번호" 컬럼을 완전히 제거하고, 프로그램이 메일 본문의 HTML 표를 렌더링하는 시점에 수신자별로 1, 2, 3... 순번을 자동 생성하여 표의 맨 왼쪽 열로 삽입합니다.
2. 현재 작업 경로의 `signature.html` 파일을 자동 탐색하거나 CLI 옵션(`--signature`)으로 지정된 HTML 서명 파일을 읽어, 메일 본문의 맨 하단(제품 표 아래)에 서명을 자동으로 병합합니다.

## User Stories

1. 실무자로서, 나는 엑셀에 "번호" 컬럼을 기입하지 않아도 메일 본문의 제품 표에 일련번호가 자동으로 매겨지길 원한다. 그래야 제품 추가·삭제 시 번호를 수동으로 재정렬할 필요가 없기 때문이다.
2. 실무자로서, 나는 엑셀 `TableData` 시트에서 "번호" 컬럼을 아예 제거하고 제품코드와 제품명만 관리하고 싶다. 그래야 데이터 입력이 간소화되기 때문이다.
3. 실무자로서, 나는 메일 본문 하단에 회사 서명이 자동으로 붙기를 원한다. 그래야 수신 고객사에게 공식적이고 신뢰감 있는 메일로 전달되기 때문이다.
4. 실무자로서, 나는 서명 파일을 HTML 형식으로 직접 관리하고 싶다. 그래야 서명 디자인을 자유롭게 편집할 수 있기 때문이다.
5. 실무자로서, 나는 `--signature` 옵션을 지정하지 않아도 현재 폴더에 `signature.html`이 있으면 자동으로 적용되길 원한다. 그래야 매번 옵션을 기재할 필요 없이 간편하게 사용할 수 있기 때문이다.
6. 실무자로서, 나는 서명 파일이 없을 때 프로그램이 에러 없이 정상 작동하길 원한다. 그래야 서명이 불필요한 상황에서도 동일한 명령어를 쓸 수 있기 때문이다.
7. 실무자로서, 나는 모든 메일에 동일한 서명이 일괄 적용되길 원한다. 그래야 발신 계정에 관계없이 통일된 대외 이미지를 유지할 수 있기 때문이다.

## Implementation Decisions

- **"번호" 컬럼 제거 및 자동 생성**: `HtmlTableRenderer`가 표를 렌더링할 때 맨 왼쪽에 "번호" 헤더와 행 인덱스(1부터 시작)를 자동 삽입한다. 엑셀 `TableData` 시트에 "번호" 컬럼이 존재하면 해당 컬럼은 파싱에서 제외(무시)한다.
- **서명 파일 로딩 전략**: `MailDistributionContext`에 서명 파일 경로를 주입한다. 미지정 시 현재 작업 경로의 `signature.html`을 자동 탐색한다. 파일이 존재하면 UTF-8로 읽어 HTML 문자열로 캐싱하고, 존재하지 않으면 빈 문자열로 처리하여 에러 없이 넘어간다.
- **서명 삽입 위치**: `load_jobs()` 내부에서 맑은 고딕 폰트 랩핑 직전에, 본문 최하단(제품 표 아래)에 서명 HTML을 병합한다. 삽입 순서: 본문 텍스트 → 제품 표 → 서명.
- **CLI 옵션 확장**: `outlook_cli.py`의 `argparse`에 `--signature` 선택 옵션을 추가하여 서명 파일 경로를 명시적으로 지정할 수 있도록 한다.

## Testing Decisions

- **좋은 테스트의 기준**: 아웃룩 COM 인터페이스의 실제 동작이 아닌, `HtmlTableRenderer`의 렌더링 출력과 `MailDistributionContext.load_jobs()`가 반환하는 `MailJob.body` 필드의 외부 행동(External Behavior)만을 검증한다.
- **테스팅 심**: 기존 `core/distribution.py` 모듈의 출력을 검증하는 단일 심을 그대로 활용한다.
  - 번호 자동 매김: `HtmlTableRenderer.render()` 출력에 "번호" 헤더와 순차 숫자가 포함되는지 단언 검증.
  - 서명 적용: 모의 `signature.html` 파일을 생성한 후 `MailDistributionContext.load_jobs()` 결과의 `body`에 서명 내용이 포함되는지 단언 검증.
- **기존 테스트 참고**: `tests/test_distribution.py`의 `test_html_table_renderer`, `test_strict_prefix_matching` 등 기존 패턴을 따른다.

## Out of Scope

- 발신 계정별로 서로 다른 서명을 매핑하는 기능은 이번 범위에 포함되지 않는다.
- 서명 파일 내 이미지 임베딩(CID 인라인 이미지) 처리는 지원하지 않는다. 서명 HTML 내의 이미지는 외부 URL 참조 방식을 전제한다.
- 엑셀 `TableData` 시트의 "번호" 컬럼이 존재할 경우 해당 값을 읽어 사용하는 하위 호환 모드는 제공하지 않는다. "번호" 컬럼은 존재하더라도 무시된다.

## Further Notes

- 기존 `test_recipients_v4.xlsx`의 `TableData` 시트에서 "번호" 컬럼을 제거하는 마이그레이션이 필요하다.
- 사용자가 기존 `.eml` 서명 파일을 `.html`로 변환하여 `signature.html`로 저장해야 한다.
