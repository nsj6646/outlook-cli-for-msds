# 이슈 01: 표 번호 자동 매김 (Auto Row Numbering)

Status: resolved

## What to build

엑셀 `TableData` 시트에서 더 이상 사용자가 수동으로 "번호" 컬럼을 관리하지 않도록, 기존 엑셀 파싱 로직에서 "번호" 컬럼이 존재하더라도 이를 완전히 무시(제외)합니다.
대신 `HtmlTableRenderer`가 수신자별 취급 제품 정보 행 리스트를 기반으로 표를 렌더링할 때, 프로그램 내부에서 1부터 시작하여 순차적으로 일련번호를 매기고 맨 왼쪽 열에 "번호" 헤더와 함께 자동 삽입되도록 구현합니다.

## Acceptance criteria

- [ ] `TableData` 시트 내에 "번호" 컬럼이 포함되어 있어도 파서가 이를 무시하여 수집하지 않는다.
- [ ] 메일 본문에 삽입되는 HTML 표 렌더링 시, 엑셀에 번호 컬럼이 없었더라도 첫 번째 열로 "번호" 헤더가 출력된다.
- [ ] 표 내부 각 제품의 첫 번째 열 값은 1부터 순차적으로 1씩 증가하는 정수형 번호로 정확히 출력된다.
- [ ] 단위 테스트를 통해 렌더러에 번호 컬럼이 없는 데이터를 주입하더라도 정상적으로 표 내에 순차 번호가 렌더링되는지 보증한다.
