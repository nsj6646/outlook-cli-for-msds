# PRD: 비밀참조(Bcc) 일괄 발송 기능 지원

Status: resolved

## Problem Statement

현재 배포 도구는 수신(To)과 참조(Cc)만 개별적으로 설정하여 대량 발송할 수 있으나, 보안 및 협업 요구에 따라 수신 고객사나 참조 대상 몰래 내부 감사자 또는 관리 계정을 메일에 숨겨서 발송해야 하는 **비밀참조(Bcc)** 기능을 지원하지 못하고 있습니다.

## Solution

엑셀 명단 파일(`Recipients` 시트)에 **`Bcc`** 컬럼을 추가 제공하여, 발송자가 개별 행마다 비밀참조 대상자들의 이메일을 지정할 수 있게 지원합니다. 다중 참조와 마찬가지로 세미콜론 `;` 구분자를 이용한 여러 명 기입을 원활히 해석하여 아웃룩 비밀참조(BCC) 필드에 자동 대입합니다.

## User Stories

1. 실무자로서, 나는 엑셀 명단의 각 행에 `Bcc` 컬럼을 입력하여, 수신 고객사 모르게 본사 감사 메일 주소를 비밀참조로 안전하게 지정해 대량 발송하고 싶다.
2. 실무자로서, 나는 하나의 `Bcc` 컬럼에 세미콜론 `;` 기호로 구분하여 여러 개의 비밀참조 대상 주소를 기입하더라도 프로그램이 정상적으로 수집해 주기를 원한다.
3. 실무자로서, 나는 특정 고객사 행에 `Bcc` 값이 아예 없거나 비어 있더라도 에러 없이 정상적으로 메일이 전송되기를 원한다.
4. 개발자가 아닌 실무자가 간편하게 쓰도록 유도하기 위해, 복잡한 단일 발송용 CLI 명령어 옵션에는 비밀참조 기능을 추가하지 않고 오직 엑셀 일괄 모드에서만 직관적으로 동작하도록 단순함을 유지하고 싶다.

## Implementation Decisions

- **엑셀 파서(`ExcelParser`) 연계**: `Recipients` 시트 로딩 시 기존의 `To`, `Cc`, `Subject`, `Body` 등과 함께 **`Bcc`** 컬럼이 존재하면 추가 수집하여 각 수신 객체의 메타데이터 정보(`replace_dict` 또는 개별 객체)에 탑재한다.
- **메일 정보 구조(`MailJob`) 확장**: `MailJob` 속성에 `bcc` 필드를 추가하여, 파싱해 둔 비밀참조 이메일 목록을 바인딩한다.
- **메일 송신 서비스(`OutlookMailService`) 결합**: 아웃룩 COM 개체 메일 작성 루프에서 `mail.BCC = mail_job.bcc` 형태로 비밀참조 속성을 할당 처리한다. 다중 수신인에 대비하여 공백 및 정리를 이행한 세미콜론 연결 문자열 규격으로 할당한다.

## Testing Decisions

- **좋은 테스트의 기준**: 실제 아웃룩 프로그램 팝업 없이도 `ExcelParser`와 `MailDistributionContext.load_jobs()`를 거쳐 반환된 개별 `MailJob` 속성에 비밀참조 이메일 목록(`job.bcc`)이 올바르게 맵핑되어 채워지는지 외부 기능(External Behavior)만을 단언 검증한다.
- **테스팅 심**: 기존 `tests/test_distribution.py` 에 Bcc 컬럼 데이터가 포함된 모의 엑셀 데이터를 로드하여 `MailJob.bcc` 에 올바르게 주입되어 메일 묶음이 도출되는지 단언 검증하는 유닛 테스트를 추가한다.

## Out of Scope

- CLI 단일 메일 발송 명령어(`--to` 모드)에 `--bcc` 옵션을 새로 제공하는 범위는 이번 구현에서 제외한다. (엑셀 구동 모드 전용)
- `TableData` 시트에서 비밀참조 수신자를 동적으로 추출하거나 기입하는 시나리오는 지원하지 않는다.
