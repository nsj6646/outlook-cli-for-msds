# PRD: 제목 포맷 다변화 및 실패(스킵) 건 재송용 엑셀 자동 추출 지원

Status: resolved

## Problem Statement

수신자 이메일 발송 작업 중 메일 제목의 가시성을 높이고, 본문 상단에 공식적인 수신자 지정 문구("수신: [고객사명] [담당자명]님")를 강제 삽입해야 하는 비즈니스 요건이 필요하게 되었습니다.
또한, 필수 정보 누락 등으로 메일 발송이 실패(스킵)하여 감사 로그에 남은 대상들을 확인한 실무자가 처음부터 전체 발송을 다시 시도하지 않고, **스킵된 건들만 모아서 편리하게 재시도할 수 있도록 동일한 규격의 재송용 엑셀을 자동 추출**해 주길 원합니다.

## Solution

1. 엑셀 `Recipients` 시트에 `Company` (고객사명) 및 `Contact` (담당자명) 컬럼을 추가 수집합니다.
2. 최종 메일 제목을 `Subject` + `" - "` + `Company` 조합으로 동적 치환 생성합니다.
3. 메일 본문 최상단에 `"수신: [Company] [Contact]님<br><br>"` 양식의 수신인 머리글을 자동 결합하여 아웃룩으로 조립합니다.
4. 만약 `Company` 또는 `Contact` 컬럼이 비어있거나 누락된 수신인은 메일 작성을 스킵하고 경고 이력을 감사 로그에 기록합니다.
5. 대량 배포 모드 실행 시 단 1건이라도 스킵이 검출되면, 실행 완료 시점에 `[원본파일명]_skipped_[YYYYMMDD_HHMMSS].xlsx` 파일을 현재 디렉토리에 자동 생성합니다. 이 파일은 원본과 완전 동치인 시트 구조(`Recipients`, `TableData`)를 지니며 스킵된 행들만 골라 담아 즉각적인 재구동을 지원합니다.

## User Stories

1. 실무자로서, 나는 발송 명단의 고객사별로 다른 회사명(`Company`)을 지정하여, 메일 제목이 `물질안전정보자료 개정에 따른 제공건 - 썬케미컬`과 같이 고객사명이 붙은 양식으로 발송되기를 원한다.
2. 실무자로서, 나는 메일 본문을 매번 편집하지 않아도 본문 최상단에 `"수신: 썬케미컬 이희우 부장님"`과 같은 격식 있는 한 줄이 자동으로 삽입되기를 원한다.
3. 실무자로서, 나는 실수로 고객사명(`Company`) 또는 담당자명(`Contact`) 입력을 누락한 수신처가 있을 때 해당 메일 발송을 즉각 중단(스킵)시키고 감사 로그에 남겨 사후 보완하고 싶다.
4. 실무자로서, 나는 대량 메일 발송 후 일부 누락으로 스킵된 건들만 모인 `[원본파일명]_skipped_[날짜].xlsx` 파일이 자동으로 생성되길 원한다. 그래야 해당 엑셀 안에서 누락된 열 정보만 보완하여 그 파일 그대로 배포 도구를 재실행(재송)할 수 있기 때문이다.

## Implementation Decisions

- **엑셀 헤더 매핑 확장**: `ExcelParser`에서 `Recipients` 시트 분석 시 `Company`, `Contact` 컬럼을 필수 수집 키로 정의한다.
- **예외 스킵 정책 강화**: 파싱 루프 혹은 `MailDistributionContext.load_jobs`에서 `Company` 또는 `Contact` 컬럼 값이 비어있거나 누락되었을 시, 스킵 대상으로 분류하여 감사 로그에 `[오류/건너뜀] Company 또는 Contact 필수 정보 누락`을 기록하고 `MailJob` 변환 목록에서 배제한다.
- **스킵 정보 백업용 자료구조**: `ExcelParser`에 스킵된 행 데이터를 원본 row 단위(오리지널 `Recipients` 행 딕셔너리)로 보존 및 수집하는 리스트(`self.skipped_recipients`)를 선언한다. 마찬가지로 `TableData` 그룹에서도 스킵된 수신인에 해당하는 제품 매핑 데이터만 별도 필터링 수집한다.
- **스킵 엑셀 추출기 (`ExcelParser.export_skipped`) 신설**:
  - `openpyxl`을 활용하여 새로운 워크북을 로드하고 `Recipients` 및 `TableData` 시트를 작성한다.
  - 헤더 폰트 및 구조를 원본과 정합성 있게 보존하여 기록한다.
  - 파일명 규격: `[원본파일명]_skipped_[YYYYMMDD_HHMMSS].xlsx`
- **제목 및 본문 동적 조립**:
  - `load_jobs` 조립 흐름에서 `final_subj = rec["subject"] + " - " + rec["company"]` 로 치환한다.
  - `final_body` 의 최선두에 `f"수신: {rec['company']} {rec['contact']}님<br><br>"` 을 자동으로 추가 병합한다.

## Testing Decisions

- **좋은 테스트의 기준**: `MailDistributionContext`에 모의 엑셀을 로드했을 때 제목과 본문 첫 줄에 정상 조립되는지, 정보가 누락된 수신인은 성공적으로 스킵 처리되는지, 그리고 실제로 현재 폴더 내에 `_skipped_` 엑셀 파일이 올바른 시트 구조로 생성되는지 단언 검증한다.
- **테스팅 심**: `tests/test_distribution.py` 에 이 일련의 시나리오(Bcc, Company, Contact, Skipped Excel)를 검증하는 독립적인 테스트 케이스를 생성하여 동작을 보증한다.

## Out of Scope

- `TableData` 시트 내의 제품코드나 제품명이 누락되었을 때는 기존의 제품 파일 스킵 정책을 따르며, 이번 `Company/Contact` 엑셀 스킵 재송 파일 자동 생성 범위에만 영향을 준다.
