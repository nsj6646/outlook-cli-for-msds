# 트리아지 레이블 (Triage Labels)

에이전트 스킬은 5가지 기본 트리아지 역할을 기준으로 작동합니다. 이 파일은 해당 역할들을 이 저장소의 이슈 트래커에서 사용하는 실제 레이블 문자열에 매핑합니다.

| mattpocock/skills 내 레이블 | 트래커 내 실제 레이블 | 의미 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 메인테이너(Maintainer)가 이 이슈를 평가해야 함 |
| `needs-info`               | `needs-info`         | 제보자(Reporter)의 추가 정보 입력을 대기 중 |
| `ready-for-agent`          | `ready-for-agent`    | 상세 명세가 완료되어 에이전트가 단독으로 처리 가능함 |
| `ready-for-human`          | `ready-for-human`    | 사람이 직접 구현을 진행해야 함 |
| `wontfix`                  | `wontfix`            | 처리하지 않기로 결정함 |

스킬이 특정 역할을 언급할 때(예: "에이전트 준비 상태 트리아지 레이블 적용"), 이 테이블에서 그에 해당하는 레이블 문자열을 사용하십시오.

실제 사용하는 용어에 맞게 오른쪽 열을 수정하여 사용하십시오.
