# ADR 0001: 제품코드 접두사(Prefix) 기반 MSDS 파일 매핑 규칙 도입

## 상태 (Status)
승인됨 (Accepted)

## 컨텍스트 (Context)
각 고객사에게 메일을 대량 발송할 때, 고객사가 취급하는 제품들에 매핑되는 여러 물질안전정보자료(MSDS) 서류들을 자동으로 찾아 첨부해야 합니다.
사용자는 엑셀로 데이터를 제어하기 원하지만, 파일 경로를 일일이 엑셀에 적는 것은 오타가 잦고 유지보수가 매우 까다롭습니다.
이에 따라 실무자의 입력 공수를 최소화하고, 파일이 임의의 이름으로 지정되더라도 제품코드만 일치하면 식별할 수 있는 자동화 매칭 알고리즘이 필요합니다.

## 결정 (Decision)
지정된 MSDS 배포 대상 파일들의 파일명 시작 부분(접두사)이 해당 제품의 고유 **제품코드**로 시작한다고 전제합니다. (예: 제품코드 `P101` -> 파일명 `P101_MSDS.pdf`, `P101_v3.pdf` 등)
이후 프로그램은 `TableData` 시트에서 파싱된 각 제품의 `제품코드` 문자열로 시작하는 파일이 지정 폴더 내에 있는지 스캔(문자열 매칭)하여, 발견되는 모든 파일을 해당 고객사 메일의 첨부파일 리스트에 동적으로 추가하도록 설계합니다.

## 결과 (Consequences)
- **장점**: 엑셀 시트에 복잡하고 긴 파일 경로를 작성할 필요가 전혀 없어져 실무자의 업무 효율성이 대폭 상승합니다. 파일명이 고정되어 있지 않고 버전이 바뀌거나 부가 설명이 붙더라도 제품코드만 접두사로 유지하면 자동으로 매핑되므로 유연합니다.
- **트레이드오프 / 단점**: 폴더 내에 파일명을 정할 때 반드시 맨 앞을 제품코드로 지정해야 하는 운영상 규칙(파일명 제약조건)이 강제됩니다. 만약 해당 제품코드로 시작하는 파일이 여러 개 존재한다면 모두 첨부될 수 있으므로, 구 버전 파일은 폴더에서 이동/삭제 처리해야 합니다.
